Abstract

Remote scene visualization enables users to view remote scenes from a local site. Conventional remote visualization systems rely on video or point-cloud streaming and experience high latency and bandwidth consumption, especially under constrained network conditions. To mitigate this problem, we propose a scene-graph streaming framework for efficient, incremental remote 3D scene visualization. To be specific, on the remote side, visual observations are converted into a structured 3D scene graph represented in JSON format using 3D scene understanding techniques. The compact scene graph is then transmitted over the communication network to the local side, where it enables incremental synthesis and updating the 3D model of the remote environment. By transmitting compact, JSON-based 3D scene graphs instead of dense visual data, the proposed framework reduces communication requirements while preserving the information needed for 3D scene synthesis. Experiments in structured indoor environments demonstrate that the proposed approach achieves substantially lower latency than the image-streaming baseline under constrained network conditions. At a hotspot distance of 12.81 m with four intervening walls, it reduces the mean end-to-end latency from 1444.75 ms to 107.72 ms, representing a 92.54% reduction.

Motivation

TeleScene in one picture. Conventional remote visualization streams dense video, which costs a lot of bandwidth and adds communication latency. TeleScene streams a lightweight JSON 3D scene graph instead, and the local side synthesizes and updates the 3D scene from it.

Method Overview

System overview. On the remote side, RGB-D observations and camera poses are encoded into lightweight 3D scene graphs. Only the changed part of the graph is streamed as JSON over Fast DDS. On the local side, an immersive 3D scene is synthesized and updated incrementally from the streamed graph.

Qualitative Results

Scenes from unseen rooms in the test set. The remote side only sees partial point clouds. The local side retrieves complete assets and infers plausible poses, even for objects that were barely observed (blue boxes).

TeleScene Dataset
